# 🌿 GreenBuddy

GreenBuddy is a full-stack web application that helps users take better care of their plants by organizing plant information, tracking care schedules, and providing useful insights in one place. Instead of relying on reminders or handwritten notes, users can manage all of their plants through a simple and user-friendly dashboard.

This project was built as a learning experience to improve my skills in full-stack development using React and Spring Boot while working with REST APIs, databases, and modern web technologies.

---

## Features

* User registration and login
* Add, edit, and delete plants
* Personal plant dashboard
* Track plant health status
* Watering and fertilizer reminders
* Growth journal with photo uploads
* Plant details with care information
* Weather-based plant care suggestions
* Responsive and modern user interface

## Getting Started

### Clone the repository

```bash
git clone https://github.com/your-username/GreenBuddy.git
```

Move into the project folder:

```bash
cd GreenBuddy
```

---

## Backend Setup

1. Open the backend folder.
2. Configure your MySQL database.
3. Update the database credentials in `application.properties`.
4. Run the Spring Boot application.

The backend will start on:

```text
http://localhost:8082
```

---

## Frontend Setup

Navigate to the frontend folder:

```bash
cd frontend
```

Install dependencies:

```bash
npm install
```

Start the React application:

```bash
npm run dev
```

The frontend will be available at:

```text
http://localhost:5173
```
